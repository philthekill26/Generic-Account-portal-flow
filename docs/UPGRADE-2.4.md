# FastSpring Self-Hosted Cancellation Survey Demo — 2.4

This release names the demo for the functionality it demonstrates, updates the login
introduction and adds a purpose statement to the customer/admin workspace. It includes
the supplied FastSpring banner and the orange, charcoal and purple colour treatment
across the portal, admin panel, tabs, buttons, dialogs and API previews.

Render's BRAND_NAME controls text only. The theme is shipped in the code and prebuilt dist.

1. Extract the ZIP and replace the repository contents, including dist and public.
2. Keep BRAND_NAME=FastSpring in Render. No other environment settings need changing.
3. Deploy the latest commit in Render.
4. Refresh the browser. The title should read FastSpring | Self-Hosted Cancellation Survey Demo.

The existing Render URL and GitHub repository name can remain unchanged.
API behaviour, cancellation and uncancel functionality remain unchanged.
Build and TypeScript checks passed. Browser visual verification remains outstanding.

Suggested description:
A seller-hosted cancellation survey demo showing how to collect customer feedback,
submit it through FastSpring's Survey API, and manage subscription cancellation
from your own account portal. Includes request previews and an admin response viewer.
